# Restaurant Website UI/UX Design

## Project Overview

This project showcases a modern restaurant website designed using WordPress. The design focuses on presenting the restaurant's menu, food offerings, and brand identity through an elegant and user-friendly interface.

## Project Goals

* Create an attractive and engaging restaurant website.
* Present food items and menu categories clearly.
* Communicate the restaurant's story and dining experience.
* Maintain a consistent visual style across website sections.

## Key Features

* Restaurant menu section with food images and prices.
* Restaurant introduction and brand story.
* Food photography and visually appealing content.
* Warm color palette with cream, brown, navy, and gold tones.
* Clear typography and structured page layouts.

## Tools & Platform

* WordPress
* UI/UX Design
* Website Design

## My Contribution

Designed and arranged the website sections to create a visually appealing restaurant experience, with emphasis on layout, typography, color consistency, and food presentation.
